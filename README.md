# 근처 알림 (Android)

Android에서 지도에 목적지를 등록하고, 활성 목적지의 설정 반경 안에 들어오면 알림을 받는 Kotlin 앱입니다. 목적지와 설정은 기기에 로컬 저장됩니다.

## 현재 구현된 기능
- OpenStreetMap 지도와 지도 길게 누르기로 목적지 추가
- 목적지별 100m / 300m / 500m / 1km / 2km / 5km 알림 반경
- 여러 목적지 동시 감지, 목적지별 ON/OFF 및 삭제
- 현재 위치로 이동
- 위치 감지 시작 / 전체 중지
- 목적지 진입 시 알림과 진동·소리(시스템 설정에 따라 다를 수 있음)
- 알림을 눌렀을 때 앱에서 해당 목적지를 지도 중심에 표시
- 최근 알림 기록을 로컬에 저장하는 서비스 로직
- GPS 경계 오차로 인한 반복 알림 완화를 위한 재무장 거리 설정 로직

## 개발 환경
- Android Gradle Plugin 8.7.3
- Kotlin Android plugin 2.1.20
- compileSdk 35, minSdk 26, targetSdk 34
- Java 17
- osmdroid 6.1.20
- Google Play services Location 21.3.0

## 실행 방법
1. 저장소를 내려받아 Android Studio에서 프로젝트 폴더를 엽니다.
2. Gradle 동기화가 완료되도록 합니다.
3. 실제 기기에서 실행하고 위치·알림 권한을 허용합니다.
4. 백그라운드 감지가 필요하면 앱 정보 > 권한 > 위치에서 '항상 허용'을 설정하고 배터리 제한을 확인합니다.
5. 지도를 길게 눌러 목적지를 등록한 뒤 감지 시작을 누릅니다.

## 주의 사항
- 이 프로젝트는 이 환경에서 Android SDK/Gradle 빌드 및 실제 기기 테스트를 수행하지 않았습니다. APK는 포함되어 있지 않습니다.
- 현재 위치 업데이트와 백그라운드 감지는 Android 권한, GPS 상태, 배터리 정책 및 기기 제조사 설정의 영향을 받으며, 즉시 알림을 보장하지 않습니다.
- 지도 타일과 장소 관련 서비스는 인터넷 연결 및 OpenStreetMap 서비스 정책에 의존합니다.
- 프로젝트에는 Gradle Wrapper 파일이 포함되어 있지 않아 Android Studio에서 Gradle 설정을 확인해야 합니다.
