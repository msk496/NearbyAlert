# 근처 알림 (Android)

Android 휴대폰에서 지도에 여러 목적지를 저장하고, 활성 목적지의 설정 반경에 들어오면 알림을 받는 앱입니다. 서버 없이 목적지·설정·알림 기록을 휴대폰 로컬에 저장합니다. 지도와 장소 검색은 인터넷 연결을 사용합니다.

## 이번 버전에 포함한 기능
- 지도 길게 누르기로 목적지 추가, OpenStreetMap 지도 마커와 반경 표시
- 장소명 검색 후 검색 결과를 목적지로 등록 (Nominatim/OSM 검색 서비스 사용)
- 여러 목적지 동시 감지, 목적지별 ON/OFF 및 전체 추적 시작/중지
- 목적지 이름·반경 수정, 삭제 확인, 즐겨찾기
- 목적지별 100m/300m/500m/1km/2km/5km 반경 설정
- 현재 위치 이동, 현재 위치 기준 거리 및 마지막 위치 갱신 시간 표시
- 진입 알림을 누르면 앱이 열리고 해당 목적지를 지도 중심에 표시
- 진동·소리 설정, 알림 테스트, 최근 알림 기록 및 기록 삭제
- 선택적 도착 후 목적지 자동 비활성화
- GPS 경계 흔들림으로 인한 반복 알림 완화를 위한 150m 재무장 여유 설정
- 지속 알림에 가장 가까운 목적지까지의 거리 및 활성 목적지 수 표시
- 목적지와 설정은 기기에 로컬 저장

## 빌드
1. Android Studio에서 이 폴더를 엽니다.
2. Gradle 동기화가 끝날 때까지 기다립니다. 프로젝트는 Android Gradle Plugin 8.7.3 및 Gradle 8.9 조합을 기준으로 합니다.
3. 실제 Android 휴대폰을 USB로 연결하고 개발자 옵션/USB 디버깅을 켭니다.
4. Run 버튼으로 설치합니다.

## 첫 실행 시
- 정확한 위치 권한과 알림 권한을 허용합니다.
- 백그라운드 감지에는 앱 정보 > 권한 > 위치 > **항상 허용** 설정이 필요할 수 있습니다.
- 삼성 기기에서는 배터리 설정에서 앱의 백그라운드 사용이 제한되지 않도록 설정하는 것이 좋습니다.
- 앱에서 **감지 시작**을 눌러 지속 알림을 확인합니다.

## 주의 사항
- 이 프로젝트 소스는 이 환경에서 Android SDK/Gradle을 이용해 실제 빌드하거나 휴대폰에서 검증하지 못했습니다. Android Studio에서 빌드 및 기기 테스트가 필요하며, APK 파일은 포함되어 있지 않습니다.
- 위치 정확도와 갱신 빈도는 GPS·네트워크·기기·Android 배터리 정책에 따라 달라집니다. 1km 경계에서 즉시 알림이 발생한다고 보장할 수 없습니다.
- 화면 꺼짐/백그라운드 감지는 foreground service를 사용하지만, 사용자가 앱을 강제 종료하거나 기기 설정·권한·배터리 정책에 따라 감지가 중단되거나 지연될 수 있습니다.
- 소리와 진동은 앱 설정 외에도 Android의 앱 알림 권한, 알림 채널 및 시스템 무음/방해금지 설정의 영향을 받을 수 있습니다.
- 장소 검색과 지도 타일은 OpenStreetMap 관련 서비스를 사용하므로 인터넷이 필요하며, 해당 서비스의 이용 정책과 요청 제한을 따라야 합니다.
